Ask an LLM the same thing twice. You get two answers.

In pandas, a seed makes random results repeat. Seed is a small add-on for Claude Code that does the same for an LLM's answer. Press both buttons a few times.

Without a seed

Write a one-line slogan for an AI analytics team.

With seed 1

/seed 1 Write a one-line slogan for an AI analytics team.

These are recorded answers from Claude Haiku on 5 October 2026, played back in your browser in the order they were given. Nothing here calls a model.

Step 2 of 5

A seed fixes one answer to one question

Type /seed, a seed and your question. The first time, the model answers as usual. From then on, that seed and that question return that answer, word for word. A different seed gives you a fresh one.

Step 3 of 5

What happens to a question

The mod does not change how the model picks its words. Chat tools give no control over that. It works one level up: the first answer drawn for a seed is saved, and the seed finds it again.

Each saved answer is one small file that a person can read:

{
  "seed": "42",
  "question": "Write a one-line slogan for an AI analytics team.",
  "model": "haiku",
  "answer": "\"Turning data into decisions, one insight at a time.\"",
  "drawnAt": "2026-10-05T16:53:28.855Z",
  "sha256": "f3b787d2e728…"
}

If someone edits that file later, the fingerprint no longer matches the text and the mod refuses to show it.

Step 4 of 5

A colleague gets the same words

A seed is not tied to a chat window. The saved answer is a file in the project, so it goes wherever the project goes.

This project already carries two saved answers, so anyone can check it:

git clone https://github.com/eshwarpotturi/llm-seed
cd llm-seed
claude --plugin-dir .

/seed 42 Write a one-line slogan for an AI analytics team.

This needs a Claude Code version that supports mods. It has been run on one computer so far, not yet on a second.

Step 5 of 5

What it does not do

  • The model is still random.Only the result for a seed is fixed. Ask without /seed and answers vary as before.
  • A saved answer is one draw.It shows what the model said once, not what it usually says.
  • The question must match exactly.One changed word is a new question and a new draw.
  • It is evidence, not proof.The fingerprint catches a later edit, not someone who rewrites the answer and the fingerprint together.
  • Saved answers are plain text.Anyone who can see the project can read the questions and answers.
  • Text in, text out.No files, images, web search or earlier chat messages go with the question.

Common questions

So is it a cache?

Yes, with three differences that matter. You choose the seed, so you can ask for a new draw on purpose. The saved answers are files that travel with the project. And each one records the time it was drawn and a fingerprint.

Why not use a real seed?

Where a model's developer interface offers a seed setting, it is best effort: the same seed usually gives the same output, not always, and it can change when the provider updates the model. Chat tools do not offer it at all. Saving the answer is the only way to get an exact match every time.

What does the seed number mean?

Nothing by itself. It is a label. 42, 7 and demo-day all work.

How do I get a new answer to the same question?

Use a different seed, or delete that answer's file in the seeds folder.

Does a replay cost anything?

No. A replay reads a file. Only a first draw calls the model.

Does something like this already exist?

In parts. Developer tools cache model calls, and some model interfaces have a best-effort seed setting. This puts the idea where the work happens, as one command, with answers shared through the project.

How the numbers were made. __TOTAL__ runs on 5 October 2026 with Claude Haiku through the mod: three questions with 30 different seeds each (so 30 separate first answers per question), then one seed asked 30 more times. Two answers count as the same only if the text matches exactly, including capital letters. Thirty asks is a small sample: the counts would shift on another day or another model.

Every answer is in the data file. The code and a longer read-me are at github.com/eshwarpotturi/llm-seed. A personal demo, not an official product of any organisation.
